# Implementación del Protocolo I2C en ASM 8085

Este repositorio contiene una implementación del protocolo de comunicación I2C utilizando el microprocesador 8085 y programado en lenguaje ensamblador (ASM). Además del código fuente, se incluye un informe detallado que describe el proceso de desarrollo y funcionamiento del sistema.

## Descripción del Proyecto

El objetivo de este proyecto es simular el protocolo I2C empleando los pines SID y SOD del microprocesador 8085. El código fuente, escrito en ensamblador, permite la comunicación entre dispositivos a través de este protocolo. Para una comprensión más profunda del proceso y las decisiones de diseño, se proporciona un informe detallado en el archivo `4. I2C.docx`.

## Estructura del Repositorio

- `4. I2C.asm`: Código fuente en ensamblador que implementa el protocolo I2C en el microprocesador 8085.
- `4. I2C.docx`: Documento que ofrece una explicación detallada del proceso de implementación, incluyendo diagramas y análisis.

## Requisitos

- **Software**: Un ensamblador compatible con el microprocesador 8085 para compilar y simular el código.
- **Hardware**: Opcionalmente, un entorno que emule o implemente físicamente el microprocesador 8085 para pruebas prácticas.

## Uso

1. **Compilación**: Utiliza un ensamblador adecuado para compilar el archivo `4. I2C.asm`.
2. **Ejecución**: Carga el código compilado en un simulador del 8085 o en el hardware correspondiente.
3. **Análisis**: Consulta el documento `4. I2C.docx` para entender el funcionamiento detallado y las pruebas realizadas.

## Notas

- Este proyecto es educativo y está diseñado para demostrar la implementación del protocolo I2C en un entorno controlado.
- Se recomienda tener conocimientos previos sobre el microprocesador 8085 y el protocolo I2C para una mejor comprensión.
- Si encuentras algún problema o tienes sugerencias, no dudes en abrir un issue en este repositorio.
